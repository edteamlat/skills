# Movie finder skill

Puedes usar esta skill para buscar la información de las películas en
TMDB. Para configurarla, puedes usar cualquiera de estas dos formas:

- Instala el plug-in en claude code:

Ingresa a claude code y coloca:
```
/plugin marketplace add edteamlat/skills

/plugin install movie-finder@edteam-agent-skills
```

- Ó puedes usar la tool de skills.sh 

```bash
npx skills edteamlat/skills --skill movie-finder
```
